# Scripts

Набор вспомогательных скриптов и алиасов для работы и не только.

## Описание скриптов

| Имя               | Алиас     | Описание                                                                                                                                                   |
|:-----------------:|:---------:| ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| check-ip.sh       | -         | Проверка ip адреса на нескольких сайтах (ident.me, ip.tyk.nu, wgetip.com).                                                                                 |
| create-755.sh     | -         | Создаёт исполняемый файл и заполняет его по шаблону из папки tools/templates в зависимости от расширения в названии. Создаст пустой файл, если шаблон не найден. |
| git-file-dates.py | gitfdates | Выводит дату создания и дату изменения файла основываясь на данных из `.git`.                                                                              |
| rename-files.py   | -         | Рекурсивно переименовывает название файлов с сохранением расширения. Старое и новое имена указываются без расширения.                                      |

> список неполный

## Описание алиасов

| Алиас       | Для команды | Описание                                                             |
| ----------- | ----------- | -------------------------------------------------------------------- |
| gitka       | gitk        | Запуск gitk в фоне с отображением всех веток.                        |
| update-list | apt         | Вывод доступных обновлений.                                          |
| backupf     | cp          | Создание копии файла с добавлением номера копии (обычно для бэкапа). |
| clipf       | cat + xclip | Копирование файла в **буфер обмена**.                                |
| list-size   | du + sort   | Вывод размера папок с сортировкой по убыванию.                       |

> Для получения полной команды алиасы - `alias <alias>`.
>
> Пример: `alias list-size` вернёт `alias list-size='du -h --max-depth=1 ./ | sort -hr'`

Для вывода полного списка алиасов

```shell
cat $MYSCRIPTS/aliases/bash_aliases
```
