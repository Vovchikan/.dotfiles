# My Scripts

Набор вспомогательных скриптов и алиасов для работы и не только.

## Пример использования

После установки можно использовать алиасы:
- команды с заданными флагами
```bash
gitka
# подключение к бд в докере
psql-ucell-dev
```
- скрипты
```bash
gitfdates --help
ucell --help
transfer_ucell --help
```
и др.
