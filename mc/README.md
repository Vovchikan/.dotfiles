# Midnight Commander

## Настройка

### Настройка редактора

- `Options -> Configuration (F9 -> O -> C)`

- Убираем галочки `1) Use internal edit`, `2) Use internal view`
  Запускаем mc с нужным редактором mc
  
  ```shell
  EDITOR=vi mc
  ```

### Настройка просмотра документов

`Command -> Edit extension file (F9 -> C -> E)`
Проходим вниз файла, находим `[Include/image]`, комментируем Open и View, прописываем свои с использованием `xdg-open`

```shell
[Include/image]
Open=(xdg-open %s)
View=(xdg-open %s)
#Open=/usr/lib/mc/ext.d/image.sh open ALL_FORMATS
#View=%view{ascii} /usr/lib/mc/ext.d/image.sh view ALL_FORMATS
```

>     тоже-самое проделываем для `[Include/video]` и `[Default]`

Теперь файлы открываются в приложении по умолчанию по нажатию `Enter`

## Горячие клавиши

[Горячие клавиши](https://gist.github.com/samiraguiar/9cd4264445545cfd459d), `A - Alt, C - Ctrl, S - Shift`:

### Всякое

`A + c` - Вызвать команду `cd` (переключение каталога)

### Панели

`A + i` - Сделать панели одинаковыми
`A + o` - Открыть папку в другой панели
`C + u` - Поменять панели местами

### Файлы

`C + t` - Выбрать файл
`A + .` - Показать\спрятать `дотфайлы`
`C + x then i` - Открыть свойства файла в соседней панели
`C + x then q` - Открыть содержимое файла в соседней панели
`C + x then s` -  Создать символическую ссылку
`S + F6` - Переименовать файл
`C + x then C + s` - Изменить символическую ссылку

### История

`A + S + h` - История
`A + y` - Назад по истории
`A + u` - Вперёд по истории 
`С + \` - Закладки

### Выделение

`S + =` - Вызвать команду для выделения по шаблону
`S + ⬇️\⬆️` - Выделить файл\папку под курсором и переместить курсор вниз\вверх
`C + t` - Выбрать файл\папку под курсором и переместить курсор вниз
