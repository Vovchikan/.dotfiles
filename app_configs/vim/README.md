## Установка

1. **Линковка конфигов**:
   
   `./link.sh`
   
   > не сработает, если ссылки уже созданы

2. **Запуск Vim**. Менеджер `vim-plug` автоматически установится сам, после чего установит все объявленные плагины.

## Плагины

| Название     | Описание                | Источник                                                      |
|:------------ |:----------------------- |:------------------------------------------------------------- |
| `indentLine` | Отображает вложенность. | [Yggdroot/indentLine](https://github.com/Yggdroot/indentLine) |

## Кастомные хоткеи

| Хоткей      | Режим  | Действие                                                                                        |
|:----------- |:------ |:----------------------------------------------------------------------------------------------- |
| `<F5>`      | Normal | Удаляет все пробельные символы в конце строк (trailing whitespace)                              |
| `//`        | Visual | Ищет выделенный визуально текст (удобно для быстрого поиска)                                    |
| `<C-Left>`  | Normal | Переключается на предыдущую вкладку (tab)                                                       |
| `<C-Right>` | Normal | Переключается на следующую вкладку (tab)                                                        |
| `p`         | Visual | Вставляет содержимое буфера обмена поверх выделенного текста, не заменяя регистр "по умолчанию" |

## Как добавить новый плагин

1. Найти нужный плагин на GitHub (например, `author/plugin-name`).

2. Открыть `.vimrc`, внутри блоков `call plug#begin(...)` и `call plug#end()` вставить:
   
   `Plug 'author/plugin-name'`

3. Сохранить `.vimrc`, открыть vim (если он был открыть тогда надо перезагрузить конфиг командой `:source ~/.vimrc`) и выполнить:
   
   `:PlugInstall`

4. При необходимости добавить настройку плагина после строки `Plug`.

## Как работает менеджер плагинов **vim-plug**

1. **Автоустановка:** При первом запуске Vim скрипт проверяет наличие файла `plug.vim` в директории `~/.vim/autoload/`. Если его нет, он автоматически скачивается с GitHub с помощью `curl`.

2. **Команды для управления:**
   
   - `:PlugInstall` — установить новые плагины
   - `:PlugUpdate` — обновить установленные
   - `:PlugClean` — удалить плагины, которые больше не перечислены в `.vimrc`

3. **Ленивая загрузка (опционально):** Плагины можно настроить на загрузку только для определённых файлов или команд (не используется в текущей конфигурации).
